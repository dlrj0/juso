# 필지검색 허브 - 주소 대량 검색 자동화 방법 검토

작성일: 2026-08-11

## 배경

- 엑셀 매크로로 공무원 PC에서 지도/드론사진 사이트에 주소 수천 건을 검색하려는 작업
- 현재 방식(창 전환 + `SendKeys`)은 보안 개선(랜덤 지연, 창 재활용 방지, 사이트 대조 등)을 적용해도 **OS 전역 입력 이벤트가 발생한다는 근본 구조는 그대로**라 보안 프로그램(EDR)이 감지할 여지가 남아있음
- API 사용 불가(드론사진 제공 사이트 등은 API 미제공/로그인 세션 필요)

## 검토한 방법 비교

| 방법 | 방식 | 전역 입력 이벤트 | 설치/승인 필요 | 상태 자동 확인 | 비고 |
|---|---|---|---|---|---|
| 1. 하이퍼링크 URL 검색 | 주소별 검색 URL을 하이퍼링크로 생성 후 클릭 | 없음 | 불필요 | 불가(사람이 확인) | 이미 사용 중인 방식과 동일 계열, 제외됨 |
| 2. 창 전환 + SendKeys (현재) | `SetForegroundWindow` + `keybd_event`/`SendKeys` | **있음** | 불필요 | 불가 | 지금 쓰고 있는 방식. 리스크 완화는 했지만 근본 구조는 동일 |
| 3. Selenium / Playwright | 브라우저 DOM에 코드가 직접 값 입력 (CDP 프로토콜) | 없음 | **필요** (Python, chromedriver 등 설치·승인) | 가능(결과 텍스트 직접 파싱) | 가장 깨끗하지만 승인 절차 필수 |
| 4. VBA COM 브라우저 제어 (`InternetExplorer.Application`) | Windows 내장 COM으로 브라우저를 열고 DOM에 직접 값 입력 | 없음 | **불필요** (Windows 내장 기능) | 가능(`Document.getElementById(...).innerText` 등) | IE 엔진 기반이라 최신 JS 중심 사이트(카카오맵 등)에서 동작 불안정 가능 |
| 5. 반자동(클립보드까지만) | 매크로는 클립보드 복사까지만, 창 전환/붙여넣기/엔터는 사용자가 직접 | 없음 | 불필요 | 사람이 직접 확인 | 승인 없이 가장 확실하게 리스크를 없애는 방법. 수천 건이면 수작업 부담은 있음 |

## 방법별 상세

### 3. Selenium / Playwright
- Python 설치 + `pip install selenium` (또는 Playwright), chromedriver 등 필요
- 브라우저의 HTML 요소를 코드가 직접 찾아 값을 넣음 (`find_element(...).send_keys(...)`) → 화면 좌표 클릭이나 키보드 이벤트 흉내가 아님
- 검색 결과 텍스트를 코드가 읽어 Excel에 상태를 자동 기록 가능
- **공무원 PC는 설치 제한이 있을 가능성이 높으므로, 보안팀에 목적을 알리고 승인/화이트리스트 등록을 먼저 요청해야 함**

### 4. VBA COM 브라우저 제어 (`InternetExplorer.Application`)
```vba
Dim ie As Object
Set ie = CreateObject("InternetExplorer.Application")
ie.Visible = True
ie.Navigate "https://지도사이트주소"

Do While ie.Busy Or ie.ReadyState <> 4
    DoEvents
Loop

ie.Document.getElementById("search-input").Value = "서울시 종로구 ..."
ie.Document.getElementById("search-button").Click
```
- Windows에 이미 내장된 COM 인터페이스라 별도 설치·승인 불필요
- 전역 입력 API(`SetForegroundWindow`, `keybd_event`, `SendKeys`) 미사용
- **한계**: IE 엔진 기반이라 최신 JS 중심 사이트(카카오맵, 네이버지도 등)에서 렌더링이 안 되거나 불안정할 수 있음. 로그인 세션이 필요한 사이트는 별도 로그인 필요할 수 있음
- 정적이거나 단순한 검색 폼을 가진 사이트에 적합

### 5. 반자동(클립보드까지만)
- 기존 모듈에서 `ForceForegroundWindow`, `Application.SendKeys` 호출부만 제거
- 버튼 클릭 시 클립보드에 주소만 복사 → 사용자가 직접 Alt+Tab, Ctrl+V, Enter
- 자동 입력 이벤트 자체가 없어 논란의 여지가 가장 적음

## 결론 및 권장 방향

1. **승인 없이 지금 바로 리스크를 없애고 싶다면 → 방법 5 (반자동)**이 가장 확실함
2. **사이트가 단순한 검색 폼 구조라면 → 방법 4 (COM 브라우저 제어)**로 자동 입력 이벤트 자체를 제거 가능. 단, 대상 사이트(특히 최신 JS 기반 지도 사이트, 로그인 필요한 드론사진 사이트)에서 실제로 동작하는지 사전 확인 필요
3. **완전 자동화 + 상태 자동 기록까지 원한다면 → 방법 3 (Selenium/Playwright)**이 가장 이상적이나, 설치·보안팀 승인이 선행되어야 함
4. 승인되지 않은 자동화를 "탐지만 피하도록" 다듬는 방향은 다루지 않음 — 기관 PC 특성상 감사·징계 리스크가 더 크기 때문
