# 엑셀 → 지도 자동 검색 매크로 (VBA) — 허브 파일 + 자동 하이퍼링크 + 정지/재생

여러 엑셀 파일마다 매크로를 반복해서 심지 않도록, **매크로가 들어있는 "허브 파일" 하나**를 만들어두고
다른 엑셀 파일의 필지 데이터를 그 안의 작업용 시트에 붙여넣기만 하면 바로 검색을 시작할 수 있는 구조입니다.

**적용할 시트 이름 / 주소 열 / 트리거(버튼) 열**을 모두 `설정` 시트에서 입력받고,
전체 동작을 **정지/재생으로 켜고 끌 수 있으며**, "다음 검색" 링크 하나로 **다음 미검색 행을 순서대로** 진행할 수 있습니다.

기능 실행은 **양식 컨트롤 버튼이 아니라, 설정 시트에 미리 적힌 텍스트를 클릭하는 하이퍼링크 방식**입니다.
버튼을 직접 그릴 필요가 없습니다.

(엑셀 2016 기준, `.xlsm` 저장 필요)

---

## 1. 전체 설계

| 요소 | 방식 |
|---|---|
| 파일 구조 | **허브 파일 1개**(`.xlsm`) 안에 `설정` 시트 + 데이터를 붙여넣을 시트(이름은 설정에서 지정) |
| 적용 시트 지정 | `설정` 시트에서 **시트 이름**을 입력 → 그 시트에서만 자동 하이퍼링크 기능 동작 |
| 주소 열 지정 | `설정` 시트에서 **쉼표로 구분된 열 문자**를 입력 → 해당 행의 값들을 순서대로 합쳐 검색어 생성 |
| 하이퍼링크(트리거) 자동 생성 | 지정된 시트의 주소 열에 값이 입력/붙여넣기 되는 즉시 그 행에 자동 하이퍼링크 생성 |
| 트리거 열 지정 | 별도 열 지정 가능, **비워두면 주소 열 자체가 그대로 하이퍼링크** |
| **기능 실행** | `설정` 시트 **F3~F10에 미리 적힌 텍스트를 클릭**하면 해당 기능 실행 — 버튼 그리기 불필요, 파일을 열면 자동으로 하이퍼링크가 생성됨 |
| **정지 / 재생** | `설정` 시트의 "정지" / "재생" 링크 클릭 한 번으로 **모든 하이퍼링크 클릭·자동 링크 생성을 즉시 멈추거나 재개** |
| **다음 검색(순차 진행)** | 재생 상태에서 "다음 검색" 링크를 누를 때마다 **아직 검색하지 않은 다음 행**을 자동으로 찾아 검색 — 행마다 링크를 일일이 찾아 클릭할 필요 없음 |
| 지도창 지정 | "지도창 지정" 링크 클릭 → 지도창을 클릭하면 **창 핸들(hWnd)**을 기억 (세션 중 1회) |

### 정지/재생이 왜 필요한가
- 데이터를 붙여넣는 도중 실수로 잘못된 셀을 클릭해 지도가 튀어나오는 것을 방지
- 검토·수정 작업 중에는 하이퍼링크 자동 생성 자체를 잠깐 꺼둘 수 있음
- "정지" 상태에서는 하이퍼링크를 클릭해도, 주소를 입력해도 아무 것도 실행되지 않음

### "다음 검색" 링크가 왜 편한가
- 지금까지는 검색할 행의 하이퍼링크를 화면에서 찾아 직접 클릭해야 했음
- **"다음 검색" 링크 하나만 반복해서 누르면**, 매크로가 마지막으로 처리한 행 다음부터 순서대로
  주소가 있는 행을 찾아 자동으로 검색을 실행 → 각 셀 하이퍼링크를 찾아다닐 필요가 없음
- 단, **완전 자동 연속 실행은 아님** — 한 번 누르면 딱 한 행만 진행합니다.
  지도 서비스가 짧은 시간에 반복 검색을 봇으로 인식해 차단할 위험이 있어 전체 자동 순회는 권장하지 않기 때문입니다.
  (사람이 결과를 확인하면서 링크를 계속 눌러가는 정도의 속도가 안전합니다.)

### ⚠️ 필수 조건
지도는 반드시 브라우저의 **"새 창"**으로 열어야 합니다. 같은 창의 "새 탭"이면 hWnd가 같아서 구분이 안 됩니다.

## 2. 허브 파일 준비

1. 새 통합 문서를 `.xlsm`으로 저장 — 예: `필지검색_허브.xlsm`
2. 시트 구성: `설정` (고정 이름) + 데이터를 붙여넣을 시트 (이름 자유, `설정`에서 지정)
3. `설정` 시트 구성

   | 셀 | 내용 | 예시 |
   |---|---|---|
   | **B1** | 적용할 시트 이름 | `작업` |
   | **B2** | 주소를 구성하는 열 문자 (쉼표 구분) | `A` 또는 `B,C,D,E` |
   | **B3** | 트리거(하이퍼링크) 전용 열 — 비우면 B2의 첫 번째 열이 그대로 트리거 | `H` 또는 공란 |
   | B4 | 지도창 hWnd (자동 기록) | *(자동)* |
   | B5 | 지도창 제목 (자동 기록) | *(자동)* |
   | B6 | 데이터 시작 행 (헤더 제외) | `2` |
   | **B7** | **실행 상태** — "실행" 또는 "정지" (링크 클릭으로 자동 기록됨) | `실행` |
   | **B8** | **마지막 처리 행** — "다음 검색" 링크가 사용하는 진행 위치 (자동 기록) | *(자동)* |

   → 핵심 입력 셀은 **B1(시트 이름) / B2(주소 열) / B3(트리거 열)** 세 개, 나머지는 자동/링크로 관리됩니다.

4. `설정` 시트 **F열(F3~F10)**에 아래 텍스트를 미리 입력해둡니다 (파일을 열면 자동으로 하이퍼링크로 바뀝니다):

   | 셀 | 텍스트 | 클릭 시 실행되는 매크로 |
   |---|---|---|
   | F3 | 지도창 지정 | `SetMapWindow` |
   | F4 | 값만 붙여넣기 | `PasteValuesOnly` |
   | F5 | 정지 | `StopAll` |
   | F6 | 재생 | `ResumeAll` |
   | F7 | 다음 검색 | `SearchNextRow` |
   | F8 | 처음부터 다시 | `ResetPointer` |
   | F9 | 전체 재동기화 | `RebuildAllTriggers` |
   | F10 | 시트 초기화 | `ClearWorkSheet` |

5. `Alt + F11` → 표준 모듈 삽입 → 이름 `modMapSearch` → 아래 코드 붙여넣기
6. `ThisWorkbook` 더블클릭 → 통합문서 이벤트 코드 붙여넣기
7. 저장 후 파일을 닫았다가 다시 열면, `Workbook_Open`이 자동으로 F3~F10에 하이퍼링크를 걸어줍니다.
   **양식 컨트롤 버튼을 따로 그릴 필요가 없습니다.**

## 3. 표준 모듈 코드 (`modMapSearch`)

```vba
Option Explicit

#If VBA7 Then
    Private Declare PtrSafe Function GetForegroundWindow Lib "user32" () As LongPtr
    Private Declare PtrSafe Function SetForegroundWindow Lib "user32" (ByVal hwnd As LongPtr) As Long
    Private Declare PtrSafe Function IsWindow Lib "user32" (ByVal hwnd As LongPtr) As Long
    Private Declare PtrSafe Function GetWindowTextA Lib "user32" (ByVal hwnd As LongPtr, ByVal lpString As String, ByVal cch As Long) As Long
    Private Declare PtrSafe Sub Sleep Lib "kernel32" (ByVal dwMilliseconds As Long)
    Private mMapHwnd As LongPtr
#Else
    Private Declare Function GetForegroundWindow Lib "user32" () As Long
    Private Declare Function SetForegroundWindow Lib "user32" (ByVal hwnd As Long) As Long
    Private Declare Function IsWindow Lib "user32" (ByVal hwnd As Long) As Long
    Private Declare Function GetWindowTextA Lib "user32" (ByVal hwnd As Long, ByVal lpString As String, ByVal cch As Long) As Long
    Private Declare Sub Sleep Lib "kernel32" (ByVal dwMilliseconds As Long)
    Private mMapHwnd As Long
#End If

Const SETTING_SHEET As String = "설정"

' ── 0) 설정값 읽기 헬퍼 ───────────────────────────
Private Function SheetExists(ByVal wsName As String) As Boolean
    Dim ws As Worksheet
    On Error Resume Next
    Set ws = ThisWorkbook.Worksheets(wsName)
    On Error GoTo 0
    SheetExists = Not ws Is Nothing
End Function

Public Function GetWorkSheetName() As String
    Dim v As String
    v = Trim(ThisWorkbook.Worksheets(SETTING_SHEET).Range("B1").Value)
    If v = "" Then v = "작업"
    GetWorkSheetName = v
End Function

Private Function GetAddressColumns() As Variant
    Dim v As String
    v = Trim(ThisWorkbook.Worksheets(SETTING_SHEET).Range("B2").Value)
    If v = "" Then v = "A"
    GetAddressColumns = Split(v, ",")
End Function

Private Function GetTriggerColumn() As String
    Dim v As String
    v = Trim(ThisWorkbook.Worksheets(SETTING_SHEET).Range("B3").Value)
    If v = "" Then
        Dim cols As Variant
        cols = GetAddressColumns()
        v = Trim(cols(0))
    End If
    GetTriggerColumn = v
End Function

Private Function GetStartRow() As Long
    Dim v As Long
    v = Val(ThisWorkbook.Worksheets(SETTING_SHEET).Range("B6").Value)
    If v = 0 Then v = 2
    GetStartRow = v
End Function

Private Function ColLetter(ByVal ws As Worksheet, ByVal colNum As Long) As String
    ColLetter = Split(ws.Cells(1, colNum).Address(False, False), "$")(0)
End Function

' ── 0-1) 정지/재생 상태 관리 ───────────────────────
Public Function IsRunning() As Boolean
    Dim v As String
    v = Trim(ThisWorkbook.Worksheets(SETTING_SHEET).Range("B7").Value)
    IsRunning = (v <> "정지")   ' 비어있거나 "실행"이면 실행 중으로 간주
End Function

Public Sub StopAll()
    With ThisWorkbook.Worksheets(SETTING_SHEET).Range("B7")
        .Value = "정지"
        .Interior.Color = RGB(255, 199, 206)   ' 연한 빨강
        .Font.Color = RGB(156, 0, 6)
    End With
    MsgBox "모든 하이퍼링크 검색과 자동 링크 생성이 정지되었습니다." & vbCrLf & _
           "다시 시작하려면 '재생' 링크를 클릭하세요.", vbInformation
End Sub

Public Sub ResumeAll()
    With ThisWorkbook.Worksheets(SETTING_SHEET).Range("B7")
        .Value = "실행"
        .Interior.Color = RGB(198, 239, 206)   ' 연한 초록
        .Font.Color = RGB(0, 97, 0)
    End With
    MsgBox "다시 실행 상태로 전환되었습니다.", vbInformation
End Sub

' ── 0-2) 진행 위치(포인터) 관리 ─────────────────────
Public Sub ResetPointer()
    ThisWorkbook.Worksheets(SETTING_SHEET).Range("B8").Value = ""
    MsgBox "진행 위치가 초기화되었습니다. 다음 검색은 처음 행부터 시작합니다.", vbInformation
End Sub

' ── 1) 지도창 지정 (세션당 1회) ───────────────────
Public Sub SetMapWindow()
    If MsgBox("확인 후 3초 안에 지도로 쓸 창을 클릭해서 활성화하세요." & vbCrLf & _
              "(반드시 '새 창'으로 띄운 지도여야 합니다. 같은 창의 탭이면 구분이 안 됩니다)", _
              vbOKCancel + vbInformation, "지도 창 지정") <> vbOK Then Exit Sub

    Dim i As Integer
    For i = 3 To 1 Step -1
        Application.StatusBar = i & "초 후 지정..."
        Sleep 1000
    Next i
    Application.StatusBar = False

    mMapHwnd = GetForegroundWindow()

    Dim buf As String, title As String
    buf = String$(255, vbNullChar)
    GetWindowTextA mMapHwnd, buf, 255
    title = Left$(buf, InStr(buf, vbNullChar) - 1)

    ThisWorkbook.Worksheets(SETTING_SHEET).Range("B4").Value = CStr(mMapHwnd)
    ThisWorkbook.Worksheets(SETTING_SHEET).Range("B5").Value = title

    MsgBox "지도창 지정 완료: " & title, vbInformation
End Sub

' ── 2) 여러 열 값을 합쳐 검색어 생성 ──────────────
Private Function BuildAddress(ByVal ws As Worksheet, ByVal targetRow As Long) As String
    Dim cols As Variant, c As Variant
    Dim parts() As String
    Dim n As Long, v As String
    cols = GetAddressColumns()

    ReDim parts(UBound(cols))
    n = -1
    For Each c In cols
        v = Trim(ws.Range(Trim(c) & targetRow).Value)
        If v <> "" Then
            n = n + 1
            parts(n) = v
        End If
    Next c

    If n < 0 Then
        BuildAddress = ""
    Else
        ReDim Preserve parts(n)
        BuildAddress = Join(parts, " ")
    End If
End Function

' ── 3) 행별 검색 실행 (정지 상태면 실행 안 함) ──────
Public Sub SearchOnMap(ByVal targetRow As Long)
    If Not IsRunning() Then
        MsgBox "현재 '정지' 상태입니다. 설정 시트에서 '재생' 링크를 먼저 클릭해주세요.", vbExclamation
        Exit Sub
    End If

    If Not SheetExists(GetWorkSheetName()) Then
        MsgBox "설정!B1에 지정한 시트를 찾을 수 없습니다.", vbExclamation
        Exit Sub
    End If

    Dim ws As Worksheet
    Set ws = ThisWorkbook.Worksheets(GetWorkSheetName())

    Dim addr As String
    addr = BuildAddress(ws, targetRow)

    If addr = "" Then
        MsgBox targetRow & "행에 주소가 없습니다. (설정!B2의 열 지정을 확인하세요)", vbExclamation
        Exit Sub
    End If

    If mMapHwnd = 0 Then
        On Error Resume Next
        mMapHwnd = CLng(ThisWorkbook.Worksheets(SETTING_SHEET).Range("B4").Value)
        On Error GoTo 0
    End If
    If mMapHwnd = 0 Or IsWindow(mMapHwnd) = 0 Then
        MsgBox "지도창이 지정되지 않았거나 닫혔습니다. 먼저 재지정하세요.", vbExclamation
        Exit Sub
    End If

    SetClipboardText addr
    SetForegroundWindow mMapHwnd
    Sleep 300
    SendKeys "^a", True
    Sleep 100
    SendKeys "^v", True
    Sleep 200
    SendKeys "~", True

    ' 진행 위치 기록 (다음 검색 링크가 사용)
    ThisWorkbook.Worksheets(SETTING_SHEET).Range("B8").Value = targetRow
End Sub

' ── 4) 다음 미검색 행을 찾아 순차 검색 ──────────────
Public Sub SearchNextRow()
    If Not IsRunning() Then
        MsgBox "현재 '정지' 상태입니다. 설정 시트에서 '재생' 링크를 먼저 클릭해주세요.", vbExclamation
        Exit Sub
    End If

    If Not SheetExists(GetWorkSheetName()) Then
        MsgBox "설정!B1에 지정한 시트를 찾을 수 없습니다.", vbExclamation
        Exit Sub
    End If

    Dim ws As Worksheet
    Set ws = ThisWorkbook.Worksheets(GetWorkSheetName())

    Dim startRow As Long
    startRow = GetStartRow()

    Dim lastProcessed As Long
    lastProcessed = Val(ThisWorkbook.Worksheets(SETTING_SHEET).Range("B8").Value)

    Dim nextRow As Long
    nextRow = IIf(lastProcessed = 0, startRow, lastProcessed + 1)

    ' 주소 열들 중 가장 마지막 데이터 행 계산
    Dim cols As Variant, c As Variant, r As Long, lastDataRow As Long
    cols = GetAddressColumns()
    lastDataRow = 0
    For Each c In cols
        r = ws.Cells(ws.Rows.Count, Trim(c)).End(xlUp).Row
        If r > lastDataRow Then lastDataRow = r
    Next c

    ' 빈 행은 건너뛰고 주소가 있는 다음 행을 탐색
    Do While nextRow <= lastDataRow
        If BuildAddress(ws, nextRow) <> "" Then Exit Do
        nextRow = nextRow + 1
    Loop

    If nextRow > lastDataRow Then
        MsgBox "더 이상 검색할 행이 없습니다. (마지막 데이터 행: " & lastDataRow & ")", vbInformation
        Exit Sub
    End If

    Call SearchOnMap(nextRow)   ' 내부에서 B8에 진행 위치가 자동 기록됨
End Sub

' ── 5) 순수 텍스트 클립보드 복사 ─────────────────
Private Sub SetClipboardText(ByVal s As String)
    Dim obj As Object
    Set obj = CreateObject("MSForms.DataObject")
    obj.SetText s
    obj.PutInClipboard
End Sub

' ── 6) 값만 붙여넣기 ─────────────────────────────
Public Sub PasteValuesOnly()
    If ActiveSheet.Name <> GetWorkSheetName() Then
        MsgBox "'" & GetWorkSheetName() & "' 시트에서 붙여넣을 위치를 먼저 클릭하세요." & vbCrLf & _
               "(현재 활성 시트: " & ActiveSheet.Name & ")", vbExclamation
        Exit Sub
    End If
    On Error Resume Next
    ActiveSheet.PasteSpecial Paste:=xlPasteValues
    On Error GoTo 0
End Sub

' ── 7) 특정 행에 트리거 하이퍼링크 생성 (내부 공용) ─
Private Sub AddTriggerHyperlink(ByVal ws As Worksheet, ByVal rowNum As Long, _
                                 ByVal trigCol As String, ByVal isSameAsAddressCol As Boolean)
    If ws.Range(trigCol & rowNum).Hyperlinks.Count > 0 Then Exit Sub

    If isSameAsAddressCol Then
        ws.Hyperlinks.Add Anchor:=ws.Range(trigCol & rowNum), Address:="", _
            SubAddress:="'" & ws.Name & "'!" & trigCol & rowNum
    Else
        ws.Hyperlinks.Add Anchor:=ws.Range(trigCol & rowNum), Address:="", _
            SubAddress:="'" & ws.Name & "'!" & trigCol & rowNum, TextToDisplay:="검색"
    End If
End Sub

' ── 8) 데이터 입력/붙여넣기 시 자동으로 트리거 생성 (정지 상태면 생성 안 함) ─
Public Sub AutoFillTriggers(ByVal Sh As Object, ByVal Target As Range)
    If Not IsRunning() Then Exit Sub
    If Sh.Name <> GetWorkSheetName() Then Exit Sub

    Dim ws As Worksheet
    Set ws = Sh

    Dim cols As Variant, c As Variant
    cols = GetAddressColumns()

    Dim trigCol As String
    trigCol = GetTriggerColumn()
    If trigCol = "" Then Exit Sub

    Dim relevant As Boolean, tc As Range, colLetter As String
    relevant = False
    For Each tc In Target.Columns
        colLetter = ColLetter(ws, tc.Column)
        For Each c In cols
            If UCase(Trim(c)) = UCase(colLetter) Then relevant = True
        Next c
    Next tc
    If Not relevant Then Exit Sub

    On Error GoTo cleanup
    Application.EnableEvents = False

    Dim isSameAsAddressCol As Boolean
    isSameAsAddressCol = False
    For Each c In cols
        If UCase(Trim(c)) = UCase(trigCol) Then isSameAsAddressCol = True
    Next c

    Dim startRow As Long
    startRow = GetStartRow()

    Dim r As Range, rowNum As Long
    For Each r In Target.Rows
        rowNum = r.Row
        If rowNum >= startRow Then
            If BuildAddress(ws, rowNum) <> "" Then
                AddTriggerHyperlink ws, rowNum, trigCol, isSameAsAddressCol
            End If
        End If
    Next r

cleanup:
    Application.EnableEvents = True
End Sub

' ── 9) 하이퍼링크 클릭 처리 ───────────────────────
' 설정 시트 F열 클릭 → 기능 실행 / 작업 시트 클릭 → 지도 검색
Public Sub HandleFollowHyperlink(ByVal Sh As Object, ByVal Target As Hyperlink)
    If Sh.Name = SETTING_SHEET Then
        Select Case Target.Range.Row
            Case 3: Call SetMapWindow
            Case 4: Call PasteValuesOnly
            Case 5: Call StopAll
            Case 6: Call ResumeAll
            Case 7: Call SearchNextRow
            Case 8: Call ResetPointer
            Case 9: Call RebuildAllTriggers
            Case 10: Call ClearWorkSheet
        End Select
        Exit Sub
    End If

    If Sh.Name <> GetWorkSheetName() Then Exit Sub
    Call SearchOnMap(Target.Range.Row)
End Sub

' ── 10) 전체 재동기화 (수동 복구용) ─────────────────
Public Sub RebuildAllTriggers()
    If Not SheetExists(GetWorkSheetName()) Then
        MsgBox "설정!B1에 지정한 시트를 찾을 수 없습니다.", vbExclamation
        Exit Sub
    End If

    Dim ws As Worksheet
    Set ws = ThisWorkbook.Worksheets(GetWorkSheetName())

    Dim cols As Variant, c As Variant
    cols = GetAddressColumns()

    Dim trigCol As String
    trigCol = GetTriggerColumn()
    If trigCol = "" Then Exit Sub

    Dim isSameAsAddressCol As Boolean
    isSameAsAddressCol = False
    For Each c In cols
        If UCase(Trim(c)) = UCase(trigCol) Then isSameAsAddressCol = True
    Next c

    Dim startRow As Long, lastRow As Long, r As Long
    startRow = GetStartRow()
    lastRow = 0
    For Each c In cols
        r = ws.Cells(ws.Rows.Count, Trim(c)).End(xlUp).Row
        If r > lastRow Then lastRow = r
    Next c
    If lastRow < startRow Then
        MsgBox "'" & ws.Name & "' 시트에 데이터가 없습니다.", vbExclamation
        Exit Sub
    End If

    Application.EnableEvents = False
    Dim i As Long, cnt As Long
    cnt = 0
    For i = startRow To lastRow
        If BuildAddress(ws, i) <> "" And ws.Range(trigCol & i).Hyperlinks.Count = 0 Then
            AddTriggerHyperlink ws, i, trigCol, isSameAsAddressCol
            cnt = cnt + 1
        End If
    Next i
    Application.EnableEvents = True

    MsgBox cnt & "개 행에 검색 링크를 새로 생성했습니다.", vbInformation
End Sub

' ── 11) 작업 시트 초기화 ───────────────────────────
Public Sub ClearWorkSheet()
    Dim wsName As String
    wsName = GetWorkSheetName()
    If Not SheetExists(wsName) Then
        MsgBox "설정!B1에 지정한 시트를 찾을 수 없습니다.", vbExclamation
        Exit Sub
    End If
    If MsgBox("'" & wsName & "' 시트의 데이터를 모두 지웁니다. 계속할까요?", _
              vbYesNo + vbExclamation) <> vbYes Then Exit Sub
    Application.EnableEvents = False
    ThisWorkbook.Worksheets(wsName).Cells.Clear
    Application.EnableEvents = True
    ThisWorkbook.Worksheets(SETTING_SHEET).Range("B8").Value = ""   ' 진행 위치도 초기화
End Sub

' ── 12) 설정 시트 F열(기능 실행 링크) 자동 생성 ─────
' 파일을 열 때 Workbook_Open에서 자동 실행됨. 이미 있으면 다시 안 만듦.
Public Sub CreateActionLinks()
    Dim ws As Worksheet
    Set ws = ThisWorkbook.Worksheets(SETTING_SHEET)

    If ws.Range("F3").Hyperlinks.Count > 0 Then Exit Sub  ' 이미 생성됨

    Dim r As Long
    For r = 3 To 10
        If Trim(ws.Range("F" & r).Value) <> "" Then
            ws.Hyperlinks.Add Anchor:=ws.Range("F" & r), Address:="", _
                SubAddress:="'" & ws.Name & "'!F" & r
        End If
    Next r
End Sub
```

## 5. 기능 실행 링크 만들기 (버튼 없이)

과거 버전은 양식 컨트롤 단추 8개를 일일이 그려야 했지만, 이 버전은 **버튼을 전혀 그리지 않습니다.**

1. `설정` 시트 **F3~F10**에 아래 텍스트를 입력합니다 (이미 텍스트만 있는 상태, 아직 링크 아님):

   | 셀 | 텍스트 |
   |---|---|
   | F3 | 지도창 지정 |
   | F4 | 값만 붙여넣기 |
   | F5 | 정지 |
   | F6 | 재생 |
   | F7 | 다음 검색 |
   | F8 | 처음부터 다시 |
   | F9 | 전체 재동기화 |
   | F10 | 시트 초기화 |

2. 파일을 저장하고 **닫았다가 다시 열면**, `Workbook_Open` → `CreateActionLinks`가 자동 실행되어
   F3~F10이 파란 밑줄 하이퍼링크로 바뀝니다.
3. 이후로는 그 텍스트를 클릭하기만 하면 `HandleFollowHyperlink`가 어느 줄을 클릭했는지 보고
   해당 매크로를 실행합니다.

> 만약 파일을 이미 열어서 자동 생성 시점을 놓쳤다면, `Alt+F11` → 즉시 실행 창(`Ctrl+G`)에
> `CreateActionLinks` 입력 후 Enter 한 번만 눌러도 됩니다.

## 6. 사용 순서

1. **(최초 1회)** 지도를 **새 창**으로 열고 `설정` 시트의 "지도창 지정" 링크 클릭 → 3초 안에 지도창 클릭
2. 지도 검색창을 한 번 수동 클릭해 포커스 확보
3. `설정!B1`(시트 이름), `B2`(주소 열), 필요 시 `B3`(트리거 열) 입력
4. 원본 엑셀에서 필요한 열 복사 → 지정 시트에 "값만 붙여넣기" 링크로 붙여넣기
5. 자동으로 하이퍼링크 생성됨 → 다음 두 방식 중 편한 대로 검색
   - **개별 클릭**: 원하는 행의 하이퍼링크를 직접 클릭
   - **순차 진행**: "다음 검색" 링크를 반복 클릭 → 자동으로 다음 미검색 행으로 진행
6. 작업 중 잠깐 멈추고 싶으면 "정지", 재개하려면 "재생" 링크 클릭
7. 새 파일로 넘어갈 때는 "시트 초기화" 후 3~5번 반복 (진행 위치도 함께 초기화됨)

## 7. 점검 사항 체크리스트

- [ ] 허브 파일을 `.xlsm`으로 저장, 매크로 허용 설정 완료
- [ ] 지도를 **새 창**으로 띄웠는가 (탭 아님)
- [ ] `Workbook_SheetChange`, `Workbook_SheetFollowHyperlink`, `Workbook_Open`을 **`ThisWorkbook`**에 넣었는가
- [ ] `설정!B1`(시트 이름)이 실제 시트 이름과 정확히 일치하는가
- [ ] `설정!B2`가 이번 파일의 주소 열 구성과 맞는가 (파일 바뀔 때마다 확인)
- [ ] `설정!F3~F10`에 텍스트가 정확히 들어있고, 파일을 재실행(닫았다 열기)해서 하이퍼링크로 바뀌었는가
- [ ] `설정!B7`(실행 상태)이 의도한 대로 "실행"/"정지"인지 색상으로 한눈에 확인 가능한가
- [ ] "다음 검색"을 쓰다가 중간에 행을 수동으로 추가/삭제하면 `B8` 진행 위치가 꼬일 수 있음 → 이 경우 "처음부터 다시"로 초기화 권장
- [ ] "다음 검색"도 결국 한 번에 한 행만 진행하도록 되어 있는지 확인 (연속 자동 실행이 아님 — 봇 차단 위험 방지 목적)
- [ ] 지도창을 닫았다 다시 열면 "지도창 지정" 링크 재실행 필요
- [ ] `SetForegroundWindow` 실패 대비: 지도창을 최근에 한 번이라도 클릭해둔 상태 유지 권장
- [ ] `Sleep` 값(300~800ms)은 PC/사이트 속도에 맞게 조정
- [ ] 개인정보 보호를 위해 작업이 끝나면 시트 초기화 습관화

카카오맵 / 네이버지도 / 구글맵 등 서비스마다 검색창 로딩 속도, 페이지 갱신 방식이 달라

## 9. 추가 점검 및 향후 기능 제안

### 🟡 실제 사용하면서 생길 수 있는 문제

- **주소를 지운 뒤에도 하이퍼링크가 남아있음**: 값이 추가될 때만 링크를 생성하며, 주소를 지워도
  트리거 열의 링크는 자동으로 사라지지 않습니다. 필요하면 "주소가 비었으면 링크도 제거" 로직 추가 가능
- **검색 완료 여부 시각 표시가 없음**: "다음 검색"으로 진행할 때 어디까지 했는지는 `설정!B8`로 알 수 있지만,
  시트 상에서 눈으로 바로 보이진 않습니다. 검색 완료된 행의 배경색을 바꾸는 기능 추가 가능
- **대량 붙여넣기 시 처리 지연**: 수천 행 단위면 하이퍼링크 생성이 몇 초 멎을 수 있음 →
  "전체 재동기화"로 나중에 일괄 처리 가능
- **매크로 보안 / 백신 경고**: `SendKeys` 사용으로 일부 보안 정책에서 의심 동작으로 분류될 수 있음
- **F3~F10 링크가 안 생겼을 때**: 파일을 처음 연 시점에만 `Workbook_Open`이 실행되므로,
  코드를 방금 붙여넣은 직후라면 저장 → 닫기 → 다시 열기를 해야 하며, 급하면 즉시 실행 창에서
  `CreateActionLinks`를 한 번 직접 호출해도 됩니다.

### 🟢 있으면 편할 추가 기능 (선택)

- **여러 지도 서비스 전환**: 지도 이름별로 hWnd를 각각 저장해두고 검색 시 드롭다운으로 선택
- **검색 이력 로그**: 언제 어떤 주소를 검색했는지 별도 시트에 자동 기록
- **대상 시트 자동 생성**: `설정!B1`에 없는 시트 이름을 입력하면 자동으로 빈 시트 생성
- **주소 형식 사전 검증**: 예상 열 개수보다 적게 채워진 행(누락 의심)을 색으로 표시
- **"다음 검색" 자동 진행 속도 조절**: 사람이 결과 확인할 시간을 벌 수 있게, 클릭 대신 타이머로
  일정 간격마다 자동 진행하되 간격을 넉넉히(예: 5~10초) 주는 옵션 — 다만 여전히 봇 탐지 위험은 존재하므로 신중히 검토 필요
